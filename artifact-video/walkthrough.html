🍲 RECIPE GENIE — build walkthrough
01 · Tech stack

Recipe Genie

An ingredient-based recipe recommendation chatbot — retrieval and ranking only, no external AI model in this build.

Next.js 16 · App Router Node.js 24 LTS React 19 Tailwind CSS 4 Plain JavaScript no TypeScript no database no external AI API
02 · Problem statement

What it has to do

"I have paneer, tomato, butter and cream"
"vegan curry with chickpeas under 30 minutes"

→ recommend recipes the user can cook right now, explain what's missing, and let them drill into full steps — deterministically, with no external model.
